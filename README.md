# 查寝总分计算器（Dormitory Score Calculator）

宿委会查寝用的**总分计算小工具**：把纸质表上的「扣分绝对值」（最多 11 项）加起来，
用 100 减去它们得到寝室得分，自动写进 Excel 总表的「分数」列，并按分数生成「等级」列。
程序只在**副本**上读写，总表原件永远不动。

> 本程序是作者第一次动手写的小工具，可能还有没发现的 Bug，**计算结果仅供参考**。
> 请务必自行核实程序生成的表格内容（分数、等级、寝室号是否对得上）后再使用或上缴。
> 发现问题或有改进建议，欢迎加 QQ 反馈：**3521228485**
>
> **填扣分的规矩**：纸质版上不扣分的词段**不要填 0** —— 0 只有一个用处，
> 就是在所有非零扣分都输完之后填一次，表示「这个寝室录完了」，程序会自动结算。
> 例如某寝室 11 个词段的扣分分别是 `1,2,3,4,0,5,6,7,0,8,9`，
> 程序里就依次输 `1,2,3,4,5,6,7,8,9`，最后再输一个 `0`。

## 对 Excel 总表的要求

| 列 | 内容 |
| --- | --- |
| A 列 | 寝室号，例如 `桃花坪学生宿舍19栋201` |
| B 列 | 学院 |
| C 列 | 年级 |
| D 列 | 分数（程序写入；D1 表头为“分数”）。v2.5 起也可能是文字 **「无人」/「锁」**——第 1 格填 `w` / `s` 时写入，此时等级列留空 |
| E 列 | 等级（v2.2 起由程序写入等级文字） |
| F 列 | tag（v2.3 可选用；存三位寝室号，或用公式从 A 列提取）。**必须真的有 tag 值**——选「使用 F 列 tag」方式时 F 列空着，程序会提示「tag 列为空」并让你改选「由程序读取寝室号」（v2.5 起会自动回到选择窗口；v2.3/v2.4 则直接提示读取失败） |

程序会在总表所在文件夹生成 `副本` 文件夹（v2.3）或同层副本（v2.1/v2.2），所有修改只发生在副本里。

## 重新打包（改代码后自己生成 exe）

仓库里**没有**放打包脚本和图标（作者本地保留）。想重新打包时：

1. 安装 Python 3.10 以上（安装时勾选 `Add Python to PATH`），再装 `openpyxl`：
   ```powershell
   python -m pip install openpyxl pyinstaller
   ```
2. 在版本目录（与 `查寝总分计算器.py` 同级）执行：
   ```powershell
   python -m PyInstaller --noconfirm --clean --onefile --windowed `
     --name '查寝总分计算器' --distpath . `
     --runtime-tmpdir '.\_calc_tmp' `
     '.\查寝总分计算器.py'
   ```
3. 生成的 `查寝总分计算器.exe` 就在版本目录里。
   （想给 exe 加回图标，就在命令里加 `--icon '程序图标.ico'`，图标文件在作者本地 `本地文件/` 里。）

`--onefile` 和 `--runtime-tmpdir .\_calc_tmp` 两句建议保留：
后者让程序优先在自身目录解压，避免个别电脑“临时目录不可用”导致无法启动。
