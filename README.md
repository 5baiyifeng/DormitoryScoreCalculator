# 查寝总分计算器（Dormitory Score Calculator）

宿委会查寝用的**总分计算小工具**：把纸质表上的「扣分绝对值」（最多 11 项）加起来，
用 100 减去它们得到寝室得分，自动写进 Excel 总表的「分数」列，并按分数生成「等级」列。
程序只在**副本**上读写，总表原件永远不动。

> 本程序是作者第一次动手写的小工具，可能还有没发现的 Bug，**计算结果仅供参考**。
> 请务必自行核实程序生成的表格内容（分数、等级、寝室号是否对得上）后再使用或上缴。

## 版本对照

| 目录 | 主要特点 |
| --- | --- |
| `计算程序v2.1` | 最初版本。副本生成在原件同一层；界面会提醒“记得看看有没有写上厕所 -3”；结算后暂停 2 秒自动进入下一个寝室 |
| `计算程序v2.2` | 新增：① **等级由程序生成**（不再依赖 Excel 公式，写分数时同步写「优秀/良好/合格/不合格」）；② 启动时的**免责声明确认**；③ 结算后改为**等待按回车**再继续（防连按）；④ 覆盖已有分数时等级同步更新 |
| `计算程序v2.3` | 新增：① **寝室号匹配方式可选**——「使用F列tag（推荐）」或「由程序读取寝室号（测试中）」（从 A 列解析“楼栋号+房号”，不依赖 tag 列）；② **退格键撤销**——已按回车记录的扣分可按 Backspace 撤回重填；③ 副本改放到原件同目录下的 **`副本` 子文件夹**（不会再出现“副本 - 副本”套娃名字） |

每个版本目录里都有：

- `查寝总分计算器vX.Y.exe`：打包好的程序，双击即用（64 位 Windows 10/11，免安装 Python）
- `查寝总分计算器.py`：源代码（分档线、扣分上限等都在文件顶部）
- `使用说明.docx` / `使用说明.md`：操作说明（含免责声明、报错处理、转发注意）
- `打包.ps1`：重新打包脚本（右键 → 使用 PowerShell 运行）
- `启动（报错时用这个）.cmd`：备用启动方式
- `界面截图.png` 等：说明文档里的截图

## 对 Excel 总表的要求

| 列 | 内容 |
| --- | --- |
| A 列 | 寝室号，例如 `桃花坪学生宿舍19栋201` |
| B 列 | 学院 |
| C 列 | 年级 |
| D 列 | 分数（程序写入；D1 表头为“分数”） |
| E 列 | 等级（v2.2 起由程序写入等级文字） |
| F 列 | tag（v2.3 可选用；存三位寝室号，或用公式从 A 列提取） |

程序会在总表所在文件夹生成 `副本` 文件夹（v2.3）或同层副本（v2.1/v2.2），所有修改只发生在副本里。

## 重新打包

1. 安装 Python 3.10 以上（安装时勾选 `Add Python to PATH`）与 `openpyxl`；
2. 进入对应版本目录，右键 `打包.ps1` → 使用 PowerShell 运行；
3. 脚本会用 PyInstaller 生成单文件 exe（首次运行会自动下载打包工具）。

打包参数里的 `--onefile` 和 `--runtime-tmpdir .\_calc_tmp` 不要删除：
后者让程序优先在自身目录解压，避免个别电脑“临时目录不可用”导致无法启动。
