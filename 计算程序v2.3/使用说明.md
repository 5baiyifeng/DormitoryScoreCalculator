# 宿委会查寝总分计算器 v2.3 · 使用说明

程序位置：`D:\HUNNU\宿委会\计算程序v2.3\查寝总分计算器.exe`
代码位置：`D:\HUNNU\宿委会\计算程序v2.3\查寝总分计算器.py`

> v2.3 相比 v2.2 的新增：
> ① **寝室号来源可选**——启动时选“使用 F 列 tag（推荐）”或“由程序读取寝室号（测试中）”；
> ② **退格键撤销**——已按回车记录的扣分，可以按退格撤回重填。
> 其余功能和 v2.2 一样（等级由程序生成、结算后按回车继续、原件永不改动）。

---

## 一、它做什么

查寝时你在纸上记的是**扣分绝对值**（扣 8 分就写 8，不写 -8）。
程序把 11 个扣分段的扣分加起来，用 100 减去它们，算出寝室得分，
写进总表的“分数（D 列）”，并按分数写“等级（E 列）”。

**原件永远不动**：程序在原件旁边的 `副本` 子文件夹里生成一份带时间戳的副本，只改副本。

> v2.3 起：副本统一放进 **原件所在文件夹下的「副本」子文件夹**（没有会自动创建），
> 原件那一层不会再越积越多，也不会再出现“原件 - 副本_时间 - 副本_时间”这种套娃名字。

## 二、启动时要做的两个选择

### 第 1 步：看免责声明

红字弹窗，点“我已知晓”或按回车。内容见第七节。

### 第 2 步：选寝室号匹配方式（v2.3 新增）

弹出“选择寝室号匹配方式”，两个按钮：

| 按钮 | 含义 | 什么时候用 |
| --- | --- | --- |
| **使用F列tag（推荐）** | 靠表里已有的 F 列 tag 找行（老做法） | 表里有 tag 列，且 tag 正确时用这个 |
| **由程序读取寝室号（测试中）** | 不依赖 F 列，直接从 A 列“寝室号”解析 | 表里没有 tag 列、或 tag 列不准/没填时用 |

直接按回车 = 选推荐的 F 列 tag。关掉这个窗口 = 取消并退出程序。

选完之后再选总表原件（`.xlsx`）。程序会在原件旁新建 `副本` 文件夹，
把这次的副本放进 `副本\原件 - 副本_时间戳.xlsx`。

## 三、两种匹配方式具体怎么工作

### 方式一：使用 F 列 tag（推荐）

- 你输入 `201`，程序在 **F 列（tag）** 里找 `201` 所在的行。
- 如果 F 列是公式（如 `=SUBSTITUTE(A2,"桃花坪学生宿舍19栋","")`），
  程序读的是 Excel 上次保存时算出的值——所以这份表**至少要用 Excel 打开并保存过一次**。
- 输入必须和 F 列里的值一致（数字 `201` 和文本 `'201'` 都能对上）。

### 方式二：由程序读取寝室号（测试中）

- 程序从 **A 列寝室号** 里解析出“楼栋号 + 房号”，例如：
  - `桃花坪学生宿舍19栋201` → `19栋201`（也能用 `19-201`）
  - `天马公寓12栋305` → `12栋305`
- 你输入时，**下面三种写法都能匹配**：
  - `19栋201`（推荐，最不会认错）
  - `19-201`
  - `201`（只写房号，程序会在全表范围里找 201）
- 程序启动后状态栏会显示“已从 A 列解析出 N 个可匹配的寝室号（测试中，请核对）”，
  界面上也会常驻显示当前用的匹配方式。
- ⚠️ **测试中的提示**：只写房号（如 `201`）时，如果同一份表里**存在两个不同楼栋的同号房间**，
  程序会匹配到**先出现的那一行**。所以这份方式建议优先输入“楼栋号+房号”，并在录完后核对一遍。

## 四、录入流程

1. 在寝室号框输入寝室号，按**回车**。
2. 光标跳到第 1 个扣分格，**每填一个扣分按一次回车**，光标自动跳到下一格。
   - 纸质表上没填的格子不用管，直接在第 1 个空格里填 `0` 按回车，本次录入结束。
   - **按错了就按退格键（Backspace）**：会把上一格撤回来重填（见第四节之二）。
3. 结算：屏幕显示“本次得分：xx”和“等级：xx”，同时写入 D 列（分数）和 E 列（等级）。
4. **核对后按一次回车**进入下一个寝室（扣分格会锁住防连按）。
   也可以不按回车，直接输入下一个寝室号。
5. 全部查完，输入 `-1` 按回车 → 保存并退出，提示框给出副本路径。
   （等待确认状态下输入 `-1` 也能退出。）

> 11 个扣分格填满时自动结算，同样等你按回车再继续。

## 四之二、按错了怎么办：退格键撤销（v2.3 新增）

**已经按回车记录过的扣分，可以用退格键撤回重填**，不用把这个寝室从头录一遍。

怎么用：

1. 比如你填了第 1 格 `8`、第 2 格 `5`，都按了回车，光标停在第 3 格；
2. 发现第 2 格应该填 `3` —— 直接**按退格键（Backspace）**；
3. 程序会把第 2 格的 `5` 撤回来、光标跳回第 2 格并**自动全选**，状态栏提示
   “已撤销第 2 格（原值 5），可以重新填写，再按回车继续”；
4. 你直接敲 `3` 覆盖，按回车继续即可。

| 情况 | 程序的行为 |
| --- | --- |
| 光标在空格子里按退格 | 撤销最近按回车记录的那一格 |
| 光标在填了数字的格子里按退格 | 正常删字符（不撤销） |
| 在窗口空白处按退格 | 同样撤销最近记录的那一格 |
| 还没按回车的那一格 | 退格就是普通删字符，不需要撤销 |
| 结束标志 `0` 那一格 | 按退格可以把 `0` 撤掉，继续往后填 |
| **已结算、正在等你按回车确认时** | 退格**不撤销**（分数已写进副本，避免与已保存数据不一致） |
| 撤销后再结算 | 按新数字重新算分、重新写入 |
| 已写入副本后、又录下一个寝室时才按退格 | 只作废“最近一次”的写入：把那一行的**分数和等级清回空白**并提示。⚠️ 若那一行原来有分数（你选过“覆盖”），清空后原分数不会自动恢复，需重新录入 |

> 一句话：**退格 = 撤销最近按回车的那个数字**。结算确认之后就不好撤了，请在确认前核对好。

## 五、等级怎么定（v2.2 起由程序生成）

| 分数 | 等级 |
| --- | --- |
| 90 分及以上 | 优秀 |
| 80 ~ 89 分 | 良好 |
| 60 ~ 79 分 | 合格 |
| 60 分以下 | 不合格 |

- 写分数的同时写等级文字，**不依赖 Excel 公式重算**；
- 副本里原有的等级公式会被就地替换成等级文字（原件里的公式不动）；
- 没写分数的行，等级留空；
- 覆盖已有分数时，等级跟着新分数一起更新；
- 改分档线：改源码顶部的 `GRADE_LEVELS`，重新打包。

## 六、几种特殊情况

| 情况 | 程序的行为 |
| --- | --- |
| 该寝室已有分数 | 弹窗“该寝室已有分数，是否覆盖？ 是（Y）或否（N）”，并显示当前分数与等级 |
| 覆盖选 **是 (Y)** | 分数和等级一起更新，副本立即保存 |
| 覆盖选 **否 (N)** | 本次结果丢弃，原分数和原等级都不动 |
| 选“由程序读取寝室号”后找不到 | 提示“按当前方式（A列寝室号）没有找到 xxx”，请你核对写法 |
| 选“使用 F 列 tag”后找不到 | 提示“没有找到”，可能是表里没有 tag 或 tag 值不一致 |
| 扣分格里敲字母 | 打不进去（只允许数字） |
| 没填数字就按回车 | 提示该格还没填 |

## 八、常见报错与处理

| 报错 | 原因 | 处理办法 |
| --- | --- | --- |
| 读取失败：没有在 F 列（tag）中找到任何寝室号 | 选了不含 tag 列的表 | 改用“由程序读取寝室号”，或换含 tag 列的表 |
| 读取失败：没有在 A 列（寝室号）中解析出任何寝室号 | A 列不是寝室号，或格式里没有数字 | 确认第一列是寝室号，或改用 F 列 tag |
| 复制失败 / 写入副本失败 / Permission denied | 原件所在文件夹只读，或副本正被 Excel 打开 | 关闭 Excel 里的同名文件，或把表放到可写文件夹 |
| 找不到寝室号 | 输入与表里对不上 | 换个写法（如 `19栋201`），或核对是否选错表 |
| 双击后一闪就没 | 电脑临时目录被安全策略禁用 | 已规避；极少数情况改双击 `启动（报错时用这个）.cmd` |
| 程序出错窗口 | 程序异常 | 程序会在自己文件夹写一份 `出错日志.txt`，把它发给作者 QQ `3521228485` |

## 九、能不能转发给别人用

**可以**：对方不用装 Python、不用装任何软件，64 位 Windows 10/11 双击即用。
转发时注意：① exe 和总表都要给对方，表要放在可写文件夹；
② 首次运行点“更多信息 → 仍要运行”；③ 建议打包成 zip 发送；
④ 32 位系统需要重新打包。

## 十、以后想改规则 / 重新打包（维护者看）

- 分档线：源码顶部 `GRADE_LEVELS`（默认 90/80/60）；
- 扣分上限 / 基准分：`MAX_ITEMS`、`FULL_SCORE`；
- 寝室号解析规则：函数 `room_keys()`（正则 `(\d{1,3})\s*(?:栋|号楼|幢|舍)` 取楼栋，
  结尾 `(\d{2,4})\s*$` 取房号）；
- 打包：右键 `打包.ps1` → 使用 PowerShell 运行；两个参数不要删：
  `--onefile`、`--runtime-tmpdir .\_calc_tmp`。
- 也可以用命令行直接指定匹配方式（跳过选择窗口）：
  `查寝总分计算器.exe "D:\...\原件.xlsx" room`（`room` = A 列读取，`tag` = F 列 tag）。
