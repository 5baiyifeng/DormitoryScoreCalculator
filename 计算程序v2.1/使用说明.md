# 宿委会查寝总分计算器 · 使用说明

程序位置：`D:\HUNNU\宿委会\计算程序\查寝总分计算器.exe`
代码位置：`D:\HUNNU\宿委会\计算程序\查寝总分计算器.py`（想改功能可以改这个文件）

---

## 一、它做什么

查寝时你在纸上记的是**扣分绝对值**（扣 8 分就写 8，不写 -8）。
这个程序把 11 个扣分段的扣分加起来，用 100 减去它们，算出寝室得分，
然后自动写进 Excel 总表的“分数（D 列）”，对应行由寝室号（F 列 tag）决定。

**原件永远不动**：程序会在原件旁边自动生成一个副本，只改副本。

---

## 二、操作步骤

1. **双击** `查寝总分计算器.exe`。
2. **先看完免责声明**（红字弹窗），点“我已知晓”或直接按回车才能继续。内容见第二节之二。
3. 弹出的文件框里选择**总表原件**（例如 `D:\HUNNU\宿委会\第三学期\原件.xlsx`），确定。
   - 副本会生成在原件同一个文件夹里，名字形如
     `原件 - 副本_20260710_1432.xlsx`（时间是生成副本的时刻）。
   - 窗口下方会显示原件的路径和副本的路径，可以核对一下。
3. 在“寝室号”框里输入**三位寝室号**（例如 `405`），按**回车**。
   - 程序会在 F 列（tag）里找 405 对应哪一行。找不到会提示你核对。
4. 光标自动跳到第 1 个扣分格。**每填一个扣分按一次回车**，光标自动跳到下一格。
   - 纸质表上没填的格子，不用管，直接在第 1 个空格里填 `0` 按回车，本次录入就结束。
   - 没有扣分就填 `0`。
5. 结算：屏幕上会显示“本次得分：xx”，同时把分数写进副本的 D 列。
6. **核对分数后按一次回车**：程序进入等待确认状态（扣分格会锁住，防手快连按），
   光标已在寝室号框里，直接按回车就开始量下一个寝室；也可以不按回车，直接输入下一个寝室号。
7. 全部查完，在寝室号框里输入 `-1` 按回车 → 程序保存并退出，提示框里会给出副本路径。
   （在等待确认状态下直接输入 `-1` 也能退出。）

> 提示：11 个扣分格都填满时也会自动结算，同样等你按回车才继续。

## 三、几种特殊情况

| 情况 | 程序的行为 |
| --- | --- |
| 该寝室 D 列已有分数 | 弹窗“该寝室已有分数，是否覆盖？ 是（Y）或否（N）” |
| 覆盖弹窗选 **是 (Y)** | 用新分数覆盖，副本立即保存 |
| 覆盖弹窗选 **否 (N)** | 本次结果丢弃，分数不动，同样等你按回车再继续 |
| 寝室号不是三位数 | 提示“寝室号必须是三位整数”，重新输入 |
| F 列里找不到该寝室号 | 提示“没有找到”，检查是不是选错了原件（比如选成了别的楼栋的表） |
| 扣分格里有字母等非法字符 | 打不进去（只允许数字） |
| 没填数字就按回车 | 提示该格还没填 |

## 四、关于 Excel 的几点说明

- 程序生成副本时会重新保存一次 Excel，**分数列的单元格格式不会改**；
- “等级/等第”列如果原本是公式，公式会保留，但它的显示值需要**用 Excel 打开副本时自动重算**（
  Excel 打开时会自己算，不用你手动操作）；
- 副本每次写入都会立即保存，所以就算中途断电，之前量过的寝室也不会丢；
- 每次启动程序都会生成一份**新的带时间戳副本**，不会覆盖上一份，方便你回溯。

## 五、常见报错与处理

| 报错 | 原因 | 处理办法 |
| --- | --- | --- |
| 读取失败：没有在所选表格的 F 列（tag）中找到任何寝室号 | 选错了文件（该表没有 tag 列，或 tag 列是空的） | 选择含 tag 列的总表原件，例如 `第三学期\原件.xlsx` |
| 复制失败 / 写入副本失败 | 原件所在文件夹只读，或副本正被 Excel 打开 | 关闭 Excel 里打开的同名文件，或把原件放到可写文件夹 |
| 弹窗 `Permission denied` | 副本被 Excel 占用 | 关闭该 Excel 再重试 |
| 找不到寝室号 | 纸质表上的房间不在这次的总表里 | 核对原件是否包含该房间 |
| 双击后窗口一闪就没了 | 电脑的临时目录（TEMP）被安全策略禁用 | 当前版本已做规避（见下一节） |
| 转发给别人后对方打不开 | 详见第八节“能不能转发给别人用” | |

## 五之二、关于"临时目录"报错（已修）

早期版本运行时需要把自己解压到系统临时目录 `%TEMP%`，如果那台电脑的临时目录
被禁用、被安全软件拦住或指向了不存在的盘，就会弹出
`Could not create temporary directory!` 并且打不开。

**现在这个版本已经处理好了**：程序优先尝试在自己所在的文件夹里解压，
失败时才退回系统临时目录。已实测：把 exe 放进只读文件夹、并且去掉 TEMP/TMP 环境变量，
程序依然能正常启动和写出副本。

如果极少数电脑上仍然报这个错（例如整个磁盘都被策略锁死），
请**改双击同目录下的 `启动（报错时用这个）.cmd`**，它会先指定一个可用的临时目录再启动程序。

## 六、给维护者的备注（可以忽略）

- 计算规则：`得分 = 100 - 所有已录入扣分之和`；录入项上限 11 项。
- 副本命名：`原文件名 - 副本_YYYYMMDD_HHMM.xlsx`；同一分钟内重复启动会自动加 `(2)(3)`。
- F 列 tag 是公式时，程序读的是 Excel 上次保存的**缓存值**；
  如果原件从未被 Excel 打开过、F 列没有缓存值，请先用 Excel 打开并保存一次原件。
- 也可以把 xlsx 路径作为命令行参数传给 exe：`查寝总分计算器.exe "D:\...\原件.xlsx"`，
  这样启动后就跳过选文件这一步。

## 七、文件夹里都是些什么

| 文件 | 干什么用 | 转发给别人时要带吗 |
| --- | --- | --- |
| `查寝总分计算器.exe` | **程序本体，双击就能用**，已内含运行环境（约 33 MB） | **必须带**，只带它就够运行 |

## 八、能不能直接把 exe 转发给别人用？

**可以。** 这个 exe 已经把 Python 和用到的库都打进自身了，对方电脑
**不需要装 Python、不需要装任何软件**，Windows 10/11（64 位）双击即用。

已实测过的极端情况：把 exe 单独放进一个**只读文件夹**、并且让这台机器
**没有任何可用的临时目录**，程序依然能正常启动、正常写出 Excel 副本。

转发时请注意这 4 件事：

1. **要让对方能改 Excel**：对方还得有一份总表（`.xlsx`），而且那份表要放在
   **可写的文件夹**里（比如桌面、文档）。放在只读的共享盘上，副本就写不出来。
2. **首次运行会有安全提示**：这个 exe **没有花钱买数字签名**，Windows 可能弹出
   蓝色的"Windows 已保护你的电脑"。点 **更多信息 → 仍要运行** 即可；
   杀毒软件偶尔会误报，加白名单即可（程序只读写你选的那个 Excel）。
3. **微信/QQ 传过去可能被拦**：聊天软件有时会屏蔽 exe 或改名。
   建议用 **压缩包（.zip）** 或 U 盘/网盘发送，收到后如果文件名变成
   `xxx.exe.txt` 之类，改回 `.exe` 即可。
4. **系统版本**：这个 exe 是 64 位程序，只支持 **64 位 Windows 10/11**。
   如果对方是 32 位系统或很老的 Windows 7，需要重新打包一个对应版本
   （见第九节）。

## 九、以后想改功能 / 重新打包

1. 装一次 Python（3.10 以上即可，安装时勾选 `Add Python to PATH`）。
2. 改 `查寝总分计算器.py`（计算规则、界面文字都在里面，有中文注释）。
3. 在程序文件夹里右键 `打包.ps1` → **使用 PowerShell 运行**。
   第一次会自动下载打包工具（需要联网），完成后会在同目录重新生成
   `查寝总分计算器.exe`。
4. 想给 32 位系统用，就在第 1 步装 32 位的 Python，再执行同一份 `打包.ps1`。

打包脚本里有两个关键参数，改的时候别删：

- `--onefile`：把所有东西塞进一个 exe，方便转发；
- `--runtime-tmpdir .\_calc_tmp`：优先在 exe 所在目录解压，
  避免"临时目录不可用"导致的 `Could not create temporary directory!` 报错。
