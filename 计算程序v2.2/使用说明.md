# 宿委会查寝总分计算器 v2.2 · 使用说明

程序位置：`D:\HUNNU\宿委会\计算程序v2.2\查寝总分计算器.exe`
代码位置：`D:\HUNNU\宿委会\计算程序v2.2\查寝总分计算器.py`（想改规则改这个文件）

> v2.2 相比上一版的新增：**等级（优秀/良好/合格/不合格）由程序算出来写进表里，不再依赖 Excel 公式。**
> 上一版放在 `计算程序` 文件夹，仍然可以用；这一版是更新版本。

---

## 一、它做什么

查寝时你在纸上记的是**扣分绝对值**（扣 8 分就写 8，不写 -8）。
这个程序把 11 个扣分段的扣分加起来，用 100 减去它们，算出寝室得分，
自动写进 Excel 总表的“分数（D 列）”，并按分数把“等级（E 列）”一起写上，
对应行由寝室号（F 列 tag）决定。

**原件永远不动**：程序会在原件旁边自动生成一个副本，只改副本。

---

## 二、操作步骤

1. **双击** `查寝总分计算器.exe`。
2. **先看完免责声明**（红字弹窗），点“我已知晓”或直接按回车才能继续。内容见第十节。
3. 弹出的文件框里选择**总表原件**（例如 `D:\HUNNU\宿委会\第三学期\原件.xlsx`），确定。
   - 副本会生成在原件同一个文件夹里，名字形如
     `原件 - 副本_20261015_1432.xlsx`（时间是生成副本的时刻）。
   - 窗口下方会显示原件和副本的路径，可以核对一下。
   - 如果原件里原来有等级公式，程序会在副本里把它换成算好的等级文字，
     窗口下方会提示“等级列原有的 N 行公式已由程序接管”。
3. 在“寝室号”框里输入**三位寝室号**（例如 `405`），按**回车**。
   - 程序会在 F 列（tag）里找 405 对应哪一行。找不到会提示你核对。
4. 光标自动跳到第 1 个扣分格。**每填一个扣分按一次回车**，光标自动跳到下一格。
   - 纸质表上没填的格子，不用管，直接在第 1 个空格里填 `0` 按回车，本次录入就结束。
   - 没有扣分就填 `0`。
5. 结算：屏幕上显示“本次得分：xx”和“等级：xx”，同时把**分数写进 D 列、等级写进 E 列**。
6. **核对分数后按一次回车**进入下一个寝室：扣分格会锁住（防手快连按），
   光标已经在寝室号框里，按回车即可；也可以不按回车，直接输入下一个寝室号。
7. 全部查完，在寝室号框里输入 `-1` 按回车 → 程序保存并退出，提示框里会给出副本路径。
   （等待确认状态下直接输入 `-1` 也能退出。）

> 提示：11 个扣分格都填满时也会自动结算，同样等你按一次回车再继续。

发现任何问题，加 QQ `3521228485` 反馈即可。

## 三、等级是怎么定的（v2.2 新增）

| 分数 | 等级 |
| --- | --- |
| 90 分及以上 | 优秀 |
| 80 ~ 89 分 | 良好 |
| 60 ~ 79 分 | 合格 |
| 60 分以下 | 不合格 |

- 以前这一步要靠 Excel 公式重算；现在**程序自己判**，写分数的同时就把等级文字填进 E 列，
  用 Excel 打开副本立刻能看到，不需要重算。
- 副本里原有的等级公式会被**就地替换成等级文字**（原件里的公式不动）。
- 还没写分数的行，等级留空，不会被写上“不合格”。
- 覆盖已有分数时，等级跟着新分数一起更新。
- 想改分档线：改源码顶部的 `GRADE_LEVELS`（默认 90/80/60），重新打包即可。

## 四、几种特殊情况

| 情况 | 程序的行为 |
| --- | --- |
| 该寝室 D 列已有分数 | 弹窗“该寝室已有分数，是否覆盖？ 是（Y）或否（N）”，并显示当前的分数与等级 |
| 覆盖弹窗选 **是 (Y)** | 分数和等级一起更新为新值，副本立即保存 |
| 覆盖弹窗选 **否 (N)** | 本次结果丢弃，原分数和原等级都不动，同样等你按回车再继续 |
| 寝室号不是三位数 | 提示“寝室号必须是三位整数”，重新输入 |
| F 列里找不到该寝室号 | 提示“没有找到”，检查是不是选错了原件 |
| 扣分格里有字母等非法字符 | 打不进去（只允许数字） |
| 没填数字就按回车 | 提示该格还没填 |

## 五、关于 Excel 的几点说明

- 程序生成副本时会重新保存一次 Excel，**单元格格式不会改**；
- E 列等级现在是程序写死的文字，打开副本直接显示，不依赖公式；
- 副本每次写入都会立即保存，就算中途断电，之前量过的寝室也不会丢；
- 每次启动都会生成一份**新的带时间戳副本**，不会覆盖上一份，方便回溯。

## 六、常见报错与处理

| 报错 | 原因 | 处理办法 |
| --- | --- | --- |
| 读取失败：没有在所选表格的 F 列（tag）中找到任何寝室号 | 选错了文件（该表没有 tag 列或 tag 列为空） | 选择含 tag 列的总表原件，例如 `第三学期\原件.xlsx` |
| 复制失败 / 写入副本失败 / Permission denied | 原件所在文件夹只读，或副本正被 Excel 打开 | 关闭 Excel 里打开的同名文件，或把原件放到可写文件夹 |
| 找不到寝室号 | 纸质表上的房间不在这次的总表里 | 核对原件是否包含该房间 |
| 等级列是空的 | 那一行还没写过分数 | 用程序录入该寝室即可 |
| 等级和分数对不上 | 只可能出现在手动改了 D 列分数、却没重新用程序录入的行 | 重新录入一次该寝室 |
| 双击后窗口一闪就没了 | 电脑的临时目录被安全策略禁用 | 已规避；极少数情况改双击 `启动（报错时用这个）.cmd` |

## 七、能不能直接转发给别人用

**可以。** 对方电脑不用装 Python、不用装任何软件，双击即用（64 位 Windows 10/11）。
实测：把 exe 放进只读文件夹、并且机器没有可用临时目录，程序依然能正常启动并写出副本。

转发时注意：

1. **exe + 总表都要给**，总表要放在**可写的文件夹**里；只发 exe 没有表可算。
2. 首次运行会有蓝色“Windows 已保护你的电脑”提示 → **更多信息 → 仍要运行**。
3. 微信/QQ 可能屏蔽或改名 exe，建议打包成 zip 或用 U 盘/网盘发送。
4. 本程序是 64 位版本；32 位系统需要重新打包（下一节）。

## 八、以后想改规则 / 重新打包（维护者看）

1. 装一次 Python 3.10 以上（勾选 `Add Python to PATH`）。
2. 改 `查寝总分计算器.py`：分档线在 `GRADE_LEVELS`，判级函数是 `grade_of()`，
   扣分上限是 `MAX_ITEMS`，基准分是 `FULL_SCORE`。
3. 右键 `打包.ps1` → **使用 PowerShell 运行**，第一次会自动联网下载打包工具，
   完成后同目录重新生成 `查寝总分计算器.exe`。
4. 打包脚本里两个参数不要删：`--onefile`（合成单个 exe）、
   `--runtime-tmpdir .\_calc_tmp`（优先在 exe 所在目录解压，避免临时目录报错）。
